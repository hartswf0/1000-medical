# The Slopling's Odyssey

> When an AI-assisted coder the culture calls a "slopling" is offered a team-lead role, everyone cheers him toward the ladder. He sails a mock-epic odyssey through the islands of tech's famous climbers, drifters and refusers to find out whether saying no can be a kind of ambition, and to find the one token that would let his proud father see the work instead of the title.

A tragicomic interactive narrative and a cardboard cut-out animated film, built out of Hartmut Koenitz's **ASAPS** (Advanced Stories Authoring and Presentation System). The story was developed in ASAPS's Ideator, generated by its Story Generator as a 97-beat protostory, and then extended past ASAPS into a puppet-animation layer that performs the beats.

| | |
|---|---|
| **Form** | Interactive digital narrative (ASAPS protostory) + animated film (HTML canvas, brad-jointed puppets) |
| **Structure** | Call → Voyage → Return (Troy → the islands → Ithaca) |
| **Protagonist** | Odie Marsh, 29, AI-assisted software engineer ("slopling", "slopfeeder", "proompter") |
| **Question** | Can AI-mediated work count as know-how, and can a parent recognize it as work? |
| **Tone** | Tragicomedy. The comedy comes from the gap between how solemnly the ladder is treated and how absurd it looks up close. |
| **Status** | Story: complete generated draft (97 beats, 4 endings). Film: production milestone (15 scenes, about 4:10, 1 interactive choice). |

## Run it

- **Film:** open `film/index.html` in a browser, or view the published copy at https://claude.ai/artifact/TPDPykFT2vr6pvNP81ptoc (private). Press play with sound on. Chapter buttons jump between scenes. At the Call you choose Accept / Decline / Renegotiate / Feign madness.
- **Interactive story:** open ASAPS (https://github.com/sumo961/ASAPS_New), drag `story/slopling-odyssey.asaps-generated.json` onto the builder, and use Preview. Then save it as an ASML 2.0 project folder into `story/project/` (see `docs/ROADMAP.md`, step 1).

## The questions it leaves the audience with

- Can saying no be its own kind of ambition?
- What would a ladder look like that rewarded going deeper instead of up?
- Can AI-mediated work count as real know-how?
- Who pays when someone steps off the ladder?
- What would it take for a parent to see a child's invisible work as work?

## Representation of real people

Technologists appear as thinly veiled, drifted-name versions (Linos Torwald, Ken Tomson, Claude Shanning, Jon Carmick, Denis Hassaby, Ilya Sutskov, Gabe Newall, Andrei Karpathi, Fred Brookes, Don Knuthe). Only verified public lines are quoted, word for word (see `docs/quotes-ledger.md`). The satire is aimed at the career ladder, not the people. The film uses no photographs of them; they're identified by props and settings. Mau Piailug is portrayed with respect and is deliberately absent from the comic film cut.
